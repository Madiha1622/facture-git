\# Application de facturation



Cette application calcule le total d'un achat et affiche le nom du client.



Compilation : javac -encoding UTF-8 Facture.java

Exécution : java Facture



Exemple actuel : 3 articles à 20 dollars donnent 60 dollars.

Client : Client démonstration

Des frais fixes de livraison de 5 dollars sont ajoutés au total.

Exemple actuel : 3 articles à 20 dollars + 5 dollars de livraison donnent 65 dollars.
